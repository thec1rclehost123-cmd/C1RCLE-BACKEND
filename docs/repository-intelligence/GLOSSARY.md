# Glossary

- BFF: frontend backend-for-frontend route.
- Contract: shared schema/client/API definition.
- Fixture: deterministic local/demo data, not live persistence.
- Hold: inventory reservation before payment completion.
- Entitlement: durable ticket/access right.
- Journal: balanced financial posting record.
- Outbox: durable event/message awaiting delivery.
- Tenant: organization-scoped data/security boundary.
- Test Mode: non-live Razorpay provider environment.
- Source state: committed baseline plus current uncommitted changes.
